# راهنمای تصاویر تور مجازی بعثت

زیرساخت تور واقعی در مسیر `/virtual-tour` آماده شده است. تا قبل از دریافت فایل‌های پانوراما، هر در پیش‌نمایش رسمی همان فضا و پیام «در انتظار تصویر ۳۶۰» را نشان می‌دهد.

## فایل موردنیاز برای هر فضا

- یک تصویر پانورامای equirectangular با نسبت دقیق `2:1`
- فرمت پیشنهادی: JPG با کیفیت ۸۵ تا ۹۰ درصد
- اندازه پیشنهادی شروع: `4096×2048` پیکسل
- برای جزئیات بیشتر: `8192×4096` پیکسل، مشروط به بهینه‌سازی حجم
- دوربین در ارتفاع تقریبی چشم، تراز افقی و بدون بریدگی در محل اتصال ابتدا و انتهای تصویر
- نور و وایت‌بالانس ثابت و ترجیحاً فضای خالی از چهره افراد؛ در صورت حضور افراد، رضایت انتشار ضروری است

## ساختار پیشنهادی پوشه‌ها

```text
public/images/virtual-tour/
  unit-01-02/main.jpg
  unit-03/main.jpg
  unit-04/main.jpg
  ...
  dep-language/main.jpg
  dep-computer/main.jpg
```

پس از قرار دادن فایل، مسیر آن در `src/lib/virtual-tour/tour-config.ts` ثبت می‌شود:

```ts
export const tourScenes = {
  "unit:boys-high-school-7": {
    panorama: "/images/virtual-tour/unit-07/main.jpg",
    initialYaw: 0,
    initialPitch: 0,
    initialHfov: 105,
  },
};
```

برای تور چنداتاقه داخل یک واحد، هر اتاق یک صحنه مستقل خواهد داشت و اتصال آن‌ها با hotspotهای در/راهرو انجام می‌شود.
